# Completed pooled-family transformer comparison

`comparison.json` is the unchanged summary retrieved from Kuma evaluation job
4234451. It contains six models evaluated on one frozen plan of 23 cohorts:
three full-prior cohorts of 1024 sequences and 20 conditional cohorts of 256
sequences, for 8192 independent sequences total. Every sequence has length
1025. The six measured times are 1,4,16,64,256,1024.

Two pooled transformers each saw 6.4 million training sequences from each of
the product, shared-base and uniform-base families, or 19.2 million total.
The existing specialists each saw 6.4 million sequences from their own family.
Both pooled seeds are displayed separately; no training seeds are averaged.

Files:

- `prior_regrets.pdf` and `.png`: three panels of expected next-token regret,
  KL(true next-token distribution || transformer), averaged over the full
  family prior. Colored solid/dotted curves show pooled seeds 0/1; gray
  dashed/dash-dotted curves show specialist seeds 0/1. Only shared base has a
  second specialist. Shading is plus/minus one standard error across sequences.
- `conditional_gaps.pdf` and `.png`: cumulative pooled-minus-specialist loss,
  preserving all 20 conditional groups. Panels are product depth pairs
  (1,1),(1,8),(4,4),(8,8); uniform-base depths 0,1,4,8; and shared-base
  depths 0,1,4,8 at each alpha 0.5,1,1.5. Solid/dotted curves show pooled
  seeds 0/1. Colors indicate conditions; bars show one paired standard error.
- `receipt.json`: exact displayed means and standard errors, all conditions,
  source, independent-validation and script hashes, checkpoint and evaluation-run identifiers,
  figure sizes, semantics and output hashes.
- `validation.json`: independent audit of the source records, prepared by
  the result-validation task rather than the plotting script.

The main paper's panel (f), generated by `section3_compact_figure.py`, shows
the same cumulative gaps for the three full-prior cohorts. At time 1024 its
signed mean gaps in bits, for pooled seeds 0/1 respectively, are approximately
product +20.59/+13.99, shared base -21.11/-37.18, and uniform base +1.41/+1.55.
Exact unrounded values and paired errors are in the receipt. Positive values
mean higher pooled-transformer loss; negative values mean lower loss.

At time t the cumulative loss sums predictions of tokens 2 through t+1,
conditioned on the first token. Expected next-token regret concerns token
t+1. Gap statistics subtract losses sequence by sequence before taking means
and standard errors. Shared-base comparisons use matching specialist seeds;
product and uniform-base comparisons share the one available specialist.
Connecting lines are visual guides between measured times, not additional
estimates. The appendix figures have native widths 5.5 inches and a 7-point
minimum font.

These are transformer-versus-transformer results. They do not estimate the
Bayesian penalty for not knowing the generating family. Validated normalized
Bayesian mixture evidence is pending; no log2(3) reference is plotted. No
sequences, predictions or Bayesian references were recomputed for these plots.

Generate and verify from the repository root:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python code/scripts/multifamily_figures.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python code/scripts/multifamily_figures.py --check-only
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python code/scripts/section3_compact_figure.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python code/scripts/section3_compact_figure.py --check-only
```

The checks compare the complete displayed-statistics receipts to the saved
source and verify script and output hashes. The appendix script also checks
that all 20 conditional groups are present, that each sample count is correct,
and that visible text stays within the horizontal figure boundaries.

To rerun the independent raw-data audit after restoring the ignored local
cohorts, scores, training status files and pooled checkpoints, use:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python code/scripts/validate_multifamily_results.py
```

This script is preserved verbatim from the completed audit. It also reads
the four existing specialist checkpoints under `results/transformer/runs/`.
It recomputes the receipt from raw files and loads checkpoint metadata, but
does not repeat transformer inference. Its archived Slurm status records the
completed evaluation; it does not poll the cluster.
